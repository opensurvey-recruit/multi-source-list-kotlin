# 오베이 설문과 제휴 설문을 한 목록으로 보여 주세요

[오베이 앱](https://go.ovey.io/)은 ‘내 설문’에서 ‘오베이 설문’과 ‘제휴 설문’을 별도 탭에 보여 줍니다.

![오베이 앱 내 설문 화면](ovey-my-survey.png)

두 탭의 설문을 한 목록으로 합쳐 보여 주는 `GET /surveys`를 만들어 주세요.

## 원본

설문은 두 원본에서 가져옵니다. 지금 각 원본이 주는 설문은 아래 JSON 파일과 같습니다.

| 원본 | 지금 주는 설문 | 특징 |
| --- | --- | --- |
| 오베이 | [ovey.json](src/main/resources/sources/ovey.json) | 오베이가 직접 운영합니다. 바로 응답합니다. |
| 제휴사 | [partner.json](src/main/resources/sources/partner.json) | 다른 회사가 운영합니다. 응답이 늦거나, 실패하거나, 오지 않을 수 있습니다. |

- 두 원본은 전체 설문 목록을 한 번에 주는 기능만 있습니다. 검색이나 변경 알림은 없습니다.
- 두 원본의 설문은 알림 없이 수시로 추가, 수정, 종료, 삭제됩니다.
- 설문은 `source`와 `id`로 구분합니다.

원본을 코드로 어떻게 표현할지도 직접 정해 주세요.

## 목록

- 제목으로 검색할 수 있습니다.
- 참여 가능, 종료, 전체로 거를 수 있습니다.
- 최근 수정순, 보상 높은 순, 소요시간 짧은 순으로 정렬할 수 있습니다.
- 페이지로 나눠 볼 수 있습니다.

그 밖의 모든 것은 직접 정해 주세요.

## 실행

JDK 25로 `./gradlew bootRun`을 실행하면 `http://localhost:8080`에서 뜹니다.
